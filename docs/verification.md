# 최종 검증 기록 — 2026-09-08

## 확인한 결과

- `python -m unittest discover -s tests -v`: **27개 통과**. 무발화 취소, 최대 녹음 길이, 접촉 디바운스/재활성화, 상태 전이, API 페이로드, WAV 검사·볼륨·스테레오 변환, 표정·RGB565 변환을 확인했다.
- API가 0.1초마다 데이터를 보내는 실제 로컬 HTTP 테스트에서, 1초 요청 제한을 넘기면 작업 프로세스를 종료하고 timeout 오류로 돌아오는 것을 확인했다. 실제 OrcaRouter 유료 호출은 하지 않았다.
- 듣기 프레임 전송이 녹음보다 먼저 실행되고, 첫 화면 전송 실패 시 녹음을 시작하지 않는 회귀 테스트가 통과했다. 오류 화면이 실패해도 원래 API/녹음 오류가 보존된다.
- `python -m ai_cube --simulate`: 완료. 네트워크·오디오·GPIO 없이 상태를 실행하고 `artifacts/faces/` PNG/GIF를 생성한다.
- `python cad/enclosure.py`: 실제 STL 생성/재로딩 검증. 상세 수치는 `cad/validation.json`에 있다. shell/base 모두 단일 연결 폐곡면, 올바른 면 방향, 양의 체적이다. 설계에 정의한 부품 외곽과 케이블 공간 사이의 재료 간섭은 없다.
- 실제 CAD 기반 조립 미리보기와 표정 이미지의 외관을 확인했다. STL은 shell과 base 각1개이며 편집 원본은 `cad/enclosure.py`다.

## 코드 검토 보완

검토에서 발견한 전체 API 시간 제한과 비동기 녹음 표시 문제를 모두 수정했다. API 요청은 자식 프로세스로 격리하여 제한시간 초과 시 종료·회수한다. 키는 명령행에 넣지 않고 표준입력으로 전달한다. SPI 전송은 잠금으로 직렬화하며 상태 변경 시 프레임 전송이 끝난 뒤 반환한다.

검증은 Windows 개발 환경에서 수행했다. Pi의 GPIO/ALSA 및 systemd 실제 실행, 실물 케이스 끼움과 배선, 실제 계정 모델 권한은 별도 확인이 필요하다. 별도 기구 검토 에이전트는 실행 한도 때문에 완료되지 않았고, 제작 에이전트의 검증 결과와 원본·치수·배선 일치 여부를 주 작업에서 확인했다.
