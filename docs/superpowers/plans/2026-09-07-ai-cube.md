# AI Cube Implementation Plan

> For agentic workers: use superpowers:subagent-driven-development for the independent mechanical task; keep runtime integration in the parent task. The user delegated design and implementation. No publication or purchase is requested.

**Goal:** Build a reviewable Pi Zero 2 W voice companion prototype package.
**Architecture:** GPIO trigger, bounded ALSA recording, OrcaRouter audio chat + TTS, SPI animated face. Independent parametric enclosure.
**Tech Stack:** Python 3.11+, standard-library unittest/urllib, Pillow, gpiozero, spidev, ALSA; parametric CAD.
**Spec:** ../../design.md

## Global Constraints

- Raspberry Pi Zero 2 W; Korean spoken responses; OrcaRouter for both inference and speech.
- No recording in idle. One interaction per fresh sensor activation. Busy touches never queue.
- GPIO mapping exactly as docs/design.md. No API keys or real audio included in source.
- Enclosure has a solid hidden capacitive top. Mesh validity does not imply physical fit verification.

## Task 1 — mechanical package

Files: cad/*, docs/enclosure.md. Detailed requirements: ../../mechanical-brief.md.
- [ ] Check component envelopes and manufacturers' dimensions.

## Task 2 — runtime

Files: ai_cube/*.py, tests/*.py, pyproject.toml, .env.example.
